## Peso de los datos

El catálogo español deja de descargar los resúmenes que sus tarjetas y buscador no utilizan. Conserva sus 2 814 personas, nombres, variantes, filtros, retratos y rutas. Los resúmenes completos permanecen en las fichas y en los registros que sí los muestran.

Los datos incrustados en las páginas comparten claves y textos repetidos. Al leerlos, el navegador reconstruye el registro completo. No se recortan biografías, capítulos, relaciones, fuentes ni notas; el HTML visible y rastreable sigue completo. La auditoría de las páginas exige igualdad exacta con los datos originales después de reconstruirlos.

La compilación compara el documento HTML completo con ambos formatos mediante gzip y conserva el más pequeño. Las páginas cortas pueden seguir usando JSON ordinario cuando la compactación añade peso. Esta elección se hace al generar la web y no consume una petición del visitante.

El lector admite también el formato anterior. Se adapta el empaquetado de Cloudflare y la recuperación de los antiguos endpoints de metadatos: siguen devolviendo JSON ordinario con todos los campos. Los límites de tamaño se miden sobre las mismas fichas, con y sin compactación, para separar el ahorro de los cambios de contenido.
