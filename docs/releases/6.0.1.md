# 6.0.1 — English interface and loading

The English catalogues now use the Spanish catalogue component: relevance and alphabetical ordering, initials, century/role/region facets, 120-person pages, house editorial filtering, counts and member links. Their labels and destinations are localised.

The Atlas shares one documentary vocabulary instead of copying it into every person. An isolated reproduction of the old 2,763-person preparation exceeded Node’s 2 GB heap; the shared-vocabulary implementation took approximately 10 ms with a 20 MB process heap on the same machine. These measurements concern preparation, not complete page loading.

The main Atlas chunk no longer imports the translation source batches to obtain story labels: it shrinks from 19,479,420 bytes to approximately 577,280 bytes (uncompressed production output). This reduces download and parsing work in both languages.

The English home metadata shrinks from 4,652,198 bytes to approximately 30 KB by using compact cards and removing unrelated catalogues. Profiles include only the dictionary labels they use. The home search prepares normalized terms once and preloads its index on focus; its quieter design uses the existing colours and typography.

Challenge loads separately from reading pages, uses the same dark-theme container as Spanish, and retains complete server-rendered hub content. Difficulty and life labels are translated. Portraits require an actual image file before reserving a frame.

English display repairs cover alternative names, malformed translated names, source descriptions, image rights and credits, filter headings, and timeline titles and categories. Original names remain searchable. Published paths, IDs, original evidence, dates and map geometries are retained.

Footer support and Google Preferred Source links sit together at matching size. The Google link uses the documented source-preferences URL, with no added third-party script: [Google Search Central](https://developers.google.com/search/docs/appearance/preferred-sources#deeplink-implementation).

Validation: 716/716 tests in the full suite; 38/38 subsequent focused checks after the last loading changes; 9,210 generated pages; SSG audit with zero errors; 4,600 inherited Spanish pages with zero public-regression differences. Further final checks are recorded in the pull request. No changes to the historical regression baseline are required.
