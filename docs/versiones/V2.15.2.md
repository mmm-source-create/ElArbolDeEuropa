# V2.15.2 — Seguridad y coherencia

Actualización sobre `83893cf05b0bb1285ff91efc161676dde9c0d82e`, con V2.15 y Speed Insights ya fusionados. Corrige la cobertura de la medición, endurece la lectura del repaso y añade controles de seguridad y limpieza del repositorio.

## Cambios

- **Repaso resistente a datos incompatibles.** Una etiqueta guardada como objeto antes podía superar la validación y romper React. Se reconstruyen las preguntas con campos permitidos, tipos y tamaños acotados, referencias propias del catálogo y enlaces válidos. Los registros inválidos se descartan y los válidos conservan su contenido. Se mantienen las claves y los récords anteriores.
- **Speed Insights en ambos arranques.** Se inicializa una sola vez desde `main.jsx`, tanto al hidratar una ficha SSG como al abrir la aplicación dinámica. Se eliminan las copias por ruta; los parámetros y fragmentos de URL se excluyen de las métricas. La dependencia se fija en `2.0.0`.
- **Cabeceras de seguridad.** CSP, `nosniff`, política de referencias, protección de enmarcado y restricción de cámara/micrófono/geolocalización. La CSP autoriza por hash el aviso móvil, conserva imágenes y exportaciones, y permite Vercel Live en las vistas previas. El build comprueba los scripts de las fichas y del shell contra la política.
- **Control de seguridad en CI.** `npm run audit:security` revisa cabeceras, SVG y patrones de secretos; bloquea avisos de dependencias de nivel alto/crítico. Se ejecuta antes de las pruebas y también semanalmente. Dependabot conserva las actualizaciones de seguridad y propone actualizaciones de acciones, sin fusionarlas automáticamente.
- **Identidad y utilidades compartidas.** El paquete se llama `el-arbol-de-europa`; nombre y dominio viven en `siteConfig.js`. Los generadores y el navegador utilizan el mismo origen configurado. Se unifican helpers de metadatos y la portada inglesa, se añaden la marca a los títulos territoriales y se retiran imports sin uso.
- **Repositorio limpio.** Datos generados y sitemaps dejan de versionarse. `npm run dev` prepara los datos desde cero. El README se centra en incorporación y publicación; el uso del Atlas y el historial tienen documentos propios. Los manifiestos antiguos se archivan con su contexto.

La base histórica, sus identificadores, las claves de almacenamiento y la geometría del mapa se conservan. La duplicación extensa de los cálculos del árbol queda para una revisión específica.
